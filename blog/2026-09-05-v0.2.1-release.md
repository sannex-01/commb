We are excited to release **AICB v0.2.1** along with the **Sannex Agent SDK v0.2.1** for Python and JavaScript/TypeScript. This update brings full multi-agent scoping, centralized platform release notes synchronization with AgentOS, interactive feedback collection, and Telegram user experience enhancements.

{/* truncate */}

## What's New in v0.2.1

### 🤖 Standalone Multi-Agent Admin Studio (`/_/admin`)
- **Full Agent CRUD**: Create and manage multiple agents per AICB instance, each with independent model selection, persona prompts, channel tokens, and access tags.
- **Multiple Access Groups & Tag Filtering**: Scoped catalog and knowledge retrieval so agents only access data within their assigned security and product groups.
- **Dynamic Channels**: Per-agent WhatsApp Cloud, Telegram bot tokens, and Web Widget embed scripts configured directly via the Admin UI.

### 🔄 AgentOS Remote Releases & Sync Worker
- **Centralized Release Notes**: AICB instances automatically poll AgentOS for official platform release notes and changelogs, displaying them directly in the Admin Dashboard.
- **Bi-Directional Telemetry**: Scoped by `agent_id` for accurate analytics across multi-agent deployments.

### 📦 Sannex Agent SDK v0.2.1 (Python & TypeScript)
Both `sannex-agent` (PyPI) and `@sannex/agent` (npm) are updated to v0.2.1 in lockstep:
- Added `agent_id` parameter support across `getConfig(agentId)`, `getAgents()`, `track()`, and `syncConversation()`.
- Added `client.getReleases()` for fetching remote platform release notes.
- Added `client.sendFeedback()` for collecting user bug reports and feature requests.

### 📱 Telegram Channel Polish
- **Cleaner Product Displays**: Product catalog browsing now displays titles in a sleek 2-column inline button grid without redundant cart emojis.
- **Universal Inline Search**: `@botname <search>` now supports all products with and without image URLs using Telegram's universal article format.
- **Photo Group Ordering**: Photo albums send cleanly before the interactive catalog listing, omitting phantom second messages.

## Upgrade Instructions

### Upgrading via Docker
```bash
docker pull samakins/aicb:latest
docker compose up -d
```

### Upgrading via pip
```bash
pip install --upgrade aicb
aicb doctor
aicb start
```

### Upgrading the Sannex SDKs
```bash
# Python
pip install --upgrade sannex-agent

# Node / TypeScript
npm install @sannex/agent@latest
```
